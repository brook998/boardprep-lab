QUICK GUIDE

How Vidhyashram BoardPrep Lab works

  1. Practice TestBuild a question set from the available bank. Work at your own pace.
  2. Timed TestAttempt a question set against a countdown timer.
  3. PYQ TestChoose a verified exam year. The year and paper/set details appear with each question.
  4. Mock TestEnter the code given by the academy. The complete fixed paper opens on screen, with print and download options. The timer is set for that paper.
  5. Submit to see answersNo correct answers or explanations are shown during any test. They appear only after submission. Mock Tests are checked offline by the teacher.

An unfinished test is saved on this device and will resume after refresh. Only one active test can run in this browser at a time. This static practice site is not a high-stakes secure exam system.
